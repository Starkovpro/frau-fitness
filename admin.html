Токен GitHub

Токен нужен, чтобы кнопка «Загрузить на сайт» могла сохранить расписание в репозиторий Starkovpro/frau-fitness — дальше Vercel сам обновит сайт за минуту. Токен хранится только в этом браузере.

Как получить токен (один раз, ~3 минуты)
  1. GitHub → аватар → Settings
  2. Внизу слева: Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Token name: frau-fitness-admin. Expiration: максимум
  4. Repository access: Only select repositories → выбери frau-fitness
  5. Permissions → Repository permissions → Contents → Read and write
  6. Нажми Generate token, скопируй и вставь в поле выше

Расписание занятий

Кликни на любой текст прямо на афише — время, название занятия, тренера, период дат или название зала — и просто печатай. Кнопками ↑ ↓ × справа можно двигать и удалять строки времени. Когда всё готово — нажми «Загрузить на сайт».
