# Frau Fitness — Woman Club

Сайт женского фитнес-клуба Frau Fitness, г. Астрахань.

## Как обновить расписание

Каждую неделю замените 2 файла в папке `images/`:
- `schedule-1.png` — Зал 1 (Зелёный)
- `schedule-2.png` — Зал 2 (Оранжевый)

Просто загрузите новые файлы с теми же именами на GitHub — Vercel обновит сайт автоматически за 30 секунд.
